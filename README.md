# Wikiddle

Wikiddle is a daily Wikipedia puzzle game. The player has to guess a random mystery page by finding out the links that are on it.

## Tech stack

- JavaScript frontend
- Python backend with FastAPI
- SQL database
- Self-hosted on a Linux server
